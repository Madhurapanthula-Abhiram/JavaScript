Attribute Methods

element.hasAttribute():

  • Checks whether an attribute exists or not
  • Returns true → if attribute is present
  • Returns false → if attribute is not present
  • Useful before accessing attribute (avoids null errors)
  • Example : console.log(t1.hasAttribute("src"));

element.getAttribute()

  • Returns the value of the given attribute
  • Always returns value as string
  • Returns null → if attribute does not exist
  • Gives exact value written in HTML (not modified)
  • Difference → element.href gives full URL but getAttribute("href") gives original
  • Example : console.log(t1.getAttribute("src"));

element.setAttribute()

  • Adds a new attribute or updates existing attribute
  • If attribute exists → value is updated
  • If attribute not exist → new attribute is added
  • Overwrites previous value completely
  • Can dynamically change id, class, src, href etc
  • Example : t1.setAttribute("src", "image.jpg");

element.removeAttribute()

  • Removes the specified attribute from element
  • After removing → attribute will not exist
  • Useful for removing disabled, hidden, required etc
  • Example : t1.removeAttribute("disabled");

element.attributes

  • Returns all attributes of an element
  • Returns a collection (NamedNodeMap)
  • Not an array but can be looped using for...of
  • Each attribute has name and value
  • Useful for debugging and inspecting elements
  • Example : console.log(t1.attributes);

data-* attributes

  • Used to store custom data inside HTML elements
  • Must start with data-
  • Access using dataset property in JS
  • data-name → dataset.name
  • data-user-id → dataset.userId
  • Can set values dynamically using dataset
  • Can delete using delete keyword
  • Widely used in real-world projects
  • Example : console.log(t1.dataset.name);
