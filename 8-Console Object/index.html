Console Object

What is Console in js

  • used to print values
  • used for debugging
  • used to check the flow of the code
  • used to check the values of variables at different stages of code

Methods of Console

                
  • console.log()          ->          used to print values in console.
    • 
            
  • console.error()        ->          used to print error messages in console.
    • 
            
  • console.warn()         ->          used to print warning messages in console.
    • 
            
  • console.clear()        ->          used to clear the console.
    • 
            
  • console.assert()       ->          used to print error message if the condition is false.
    • 
            
  • console.table()        ->          used to print data in table format in console.
    • 
            
  • console.time()         ->          used to start a timer in console.
    • 
            
  • console.timeEnd()      ->          used to end a timer in console and print the time taken.
    • 
            
  • console.info()         ->          used to print information messages in console.
    • 
            
  • console.count()        ->          used to count the number of times a particular string has been logged in the console.
    • 
            
  • console.group()        ->          used to group related messages together in the console.
    • 
            
  • console.groupEnd()     ->          used to end a group of messages in the console.
    • 
            
  • console.dir()          ->          used to print the properties of an object in the console.
