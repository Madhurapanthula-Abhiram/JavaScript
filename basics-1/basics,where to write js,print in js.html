Where can we use js file

  1. in ending of the body you can write script by opening it and close script after it is finished.
  2. inside the head tag you can write script at end of the code in head by opening and closing the script tag.
  3. giving the script as seperate file script src=name.js inside the head or in body ("view the code for more details").
  4. max use at end of the body msotly used and right way to use.
  5. you can have many script files for one html file attached but it runs in order they are written
  6. if script 1 uses something from script 2 then it should be next to script 2 while writting
  7. all scripts share global space
  8. varibales can overwrite each other
  9. script type="module" src="main.js"-used for many script files so avoid errors and conflicts
