Variabes and Data Types in js

Variables

  • A variable is a container in memory that stores data.
  • Name given to a memory location that stores data is a variable.

How to Declare Variables in JavaScript(let,const,var-tells js we want to create a variable).

  1. var-The old way.
    • The data can be redeclared.
    • can be updated.
    • can cause bugs.
    • Not used now as per ES6 as we have let and const.
  2. let
    • The data cannot be redeclared in same block.
    • can be updated.
    • Block scoped.
  3. const
    • The data cannot be redeclared and updated.
    • Block scoped.
    • must be initialized with value.

Rules for Naming Variables

  1. names are case sensitive in js as it is case sensitive name and Name both are diff.
  2. letters,digits,underscore,$ are allowed no spaces are allowed!.
  3. name should not start with number.
  4. Reserved words cannot be used as names.
