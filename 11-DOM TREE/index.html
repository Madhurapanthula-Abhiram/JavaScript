Walking through DOM Tree

Key points

  • We can access and manipulate HTML using JavaScript through the DOM (Document Object Model).
  • The browser represents the HTML document as a document object.
  • This document object acts as the root of the DOM tree. but as Object
  • The browser converts HTML code into a DOM tree structure, which makes it easier to understand and modify content dynamically.
  • In the DOM tree, HTML elements are organized in a hierarchical structure from the root node to leaf nodes.

Parent , Children , Sibling nodes

Dom Navigation Properties/methods OF Parent,child Sibling

Child Naviagtion Properties

 

  • .childNodes               ->    all child nodes (elements,text,comments also) text and comments not ignored
    • 

  • .hasChildNodes()          ->    returns true if any child node exists
    • 

  • .children                 ->    only element children (ignores text/comments)
    • 

  • .children[0],[1]          ->    access specific child element by index
    • 

  • .firstChild               ->    first node (can be text like whitespace,element,comment)text ,comment not ignored
    • 

  • .lastChild                ->    last node (can be text/comment)text ,comment not ignored
    • 

  • .firstElementChild        ->    first actual element (ignores text)
    • 

  • .lastElementChild         ->    last actual element (ignores text)
    •

    Parent Navigation Properties

     

  • .parentNode              ->      returns parent node (can be element, document, or documentFragment) returns any parent
    • 

  • .parentElement           ->      returns parent only if it is an element, else null
    • 

  •  Difference              ->      parentNode can return non-elements, parentElement returns only elements
    •

    Sibling Navigation properties

     

  • .nextSibling              ->      next node right in DOM tree(can be text/comment/element)
    • 

  • .previousSibling          ->      previous node left in DOM tree(can be text/comment/element)
    • 

  • .nextElementSibling       ->      next sibling that is an element only
    • 

  • .previousElementSibling   ->      previous sibling that is an element only
    • 

  •  Difference               ->      sibling = all nodes, elementSibling = only HTML elements
    •

    Table Navigation Properties

     

  • .rows                    ->       HTMLCollection of all rows in table
    • 

  • .rows[0]                 ->       first row of the table
    • 

  • .caption                 ->       returns  element of table
    • 

  • .tHead                   ->       returns  element
    • 

  • .tBodies                 ->       HTMLCollection of all  elements
    • 

  • .tBodies[0]              ->       first  (commonly used)
    • 

  • .tBodies[i]              ->       used when multiple  exist
    • 

  • .tFoot                   ->       returns  element
    • 

  • .cells                   ->       collection of all cells (/) in a row
    • 

  • .rowIndex                ->       index of row in entire table
    • 

  • .sectionRowIndex         ->       index of row inside its section (//)
    • 

  • .cellIndex               ->       index of cell inside a row
    •

    Searching in DOM or DOM manipulation

     

  • .getElementById()               ->         returns element with given id (only one)
    • 

  • .getElementsByClassName()       ->         HTMLCollection of elements with given class
    • 

  • .getElementsByTagName()

                     

    • HTMLCollection of elements with given tag
      • 

    • works for all tags (div, p, etc.)
      • 

    • no id/class required
      • 

    

  • .querySelector()                

      

    • returns first matching element
      • 

    • supports id selector (#id)
      • 

    • supports class selector (.class)
      • 

    • supports tag selector (div, p)
      • 

    • supports descendant selection (div p)
      • 

    • supports multiple selectors (h1, p)
      • 

    • supports attribute selection ([type="text"])
      • 

    • returns null if no match found
    

  • .querySelectorAll()   

                    

    • NodeList of all matching elements
      •             

    • returns all matches (not just first)
      •
