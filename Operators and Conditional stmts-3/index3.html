Operators

JavaScript operators are used to perform actions on values and variables. Below are the main types:

  1. Arithmetic Operators
  2. Assignment Operators
  3. Comparison Operators
  4. Logical Operators
  5. Ternary Operator
  6. Bitwise Operators

Operator Details:

  • Arithmetic: +, -, *, /, %, ++, --
  • Assignment: =, +=, -=, *=, /=, %=
  • Comparison: ==, ===, !=, !==, >, <, >=, <=
  • Logical: &&, ||, !
  • Ternary: condition ? true : false
  • Bitwise: &, |, ^, ~, <<, >>, >>>

Conditional Statements

Conditional statements allow JavaScript to make decisions based on conditions.

Key Points:

  • Used to execute code only if a condition is true.
  • Can handle multiple conditions.
  • Used for controlling program flow.
  • Includes: if, else, else-if, switch, ternary operator.

Types of Operators:

  1. if stmt
  2. if-else stmt
  3. if-else if-else
  4. Nested if
  5. switch case
