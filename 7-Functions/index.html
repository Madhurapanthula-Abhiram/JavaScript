Functions in JavaScript

Functions Key Points

  • Functions are reusable blocks of code that perform a specific task.
  • Functions can take parameters and return values.
  • Functions can be defined using function declarations or function expressions.
  • Functions that are declared can be called before their definition in the code.
  • Functions that are defined by Expressions only be called after their definition in the code.
  • Functions can be called or invoked to execute the code within them.
  • Arrow Functions are used in modern JavaScript.
  • Function Syntax:
    • Function Declaration:
      function function_name(parameters)
      {
      // code
      return stmt;
      }
    • Function Expression:
      const function_name = function(parameters)
      {
      // code
      return stmt;
      };
    • Arrow Function:
      const function_name = (parameters) => {
      // code
      return stmt;
      };
  • Callback functions:A function that is passed as an argument to another function, and is executed later.(discussed further)
