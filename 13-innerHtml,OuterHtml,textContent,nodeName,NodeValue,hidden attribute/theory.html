DOM Properties:

TagName, nodeName, nodeValue, innerHTML, outerHTML, textContent, hidden

.getElementsByTagName()->Recap

  • Definition: Selects elements by tag name
  • Returns HTMLCollection (array-like)
  • Access elements using index [0], [1]
  • Not a real array (no map/forEach directly)
  • Live collection (updates automatically)
  • Example: document.getElementsByTagName("p")

nodeName

  • Definition: Returns name of the node
  • Element → TAG NAME (uppercase)
  • Text node → #text
  • Comment node → #comment
  • Example: element.nodeName

nodeValue

  • Definition: Returns value of node
  • Element node → null
  • It gives the value in it as ele do not store value directly it is null
  • for every ele node you get null access it's child and print nodevalue then you get text or comment
  • Text node → actual text
  • Comment node → comment text
  • Attribute node → attribute value
  • Example: element.firstChild.nodeValue

innerHTML

  • Definition: Gets/sets HTML inside element
  • Includes tags and content
  • Replaces all inner content when set
  • Can insert multiple elements
  • we can write nesting insertion but it inserts as siblings
  • Example: element.innerHTML = "<p>Hello</p>"

outerHTML

  • Definition: Gets/sets whole element
  • Includes element itself + content
  • Replaces entire element
  • Old variable becomes invalid after replace
  • but if stored you can acees it
  • Nesting works only if HTML is valid
  • Example: element.outerHTML = "<div>New</div>"

textContent

  • Definition: Returns only text
  • Ignores HTML tags
  • Includes hidden text
  • Safer and faster than innerHTML
  • Example: element.textContent = "Hello"

hidden attribute

  • Definition: Hides or shows element
  • Works like display: none
  • Boolean (true / false)
  • Can be set via HTML or JS
  • Example: element.hidden = true
