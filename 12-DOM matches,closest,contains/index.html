DOM Methods: matches, closest, contains

matches() Key points:

  • Checks if an element matches a given CSS selector.
  • Returns true or false.
  • Works only on the element itself.
  • Useful in event handling to identify clicked elements.
  • Example: element.matches(".className")

closest() Key points:

  • Finds the nearest ancestor (or itself) matching a selector.
  • Moves upward in the DOM tree.
  • Returns the matched element or null.
  • Very useful for event delegation.
  • Example: element.closest(".parentClass")

contains() Key points:

  • Checks if one element contains another element.
  • Returns true or false.
  • Works downward in the DOM tree.
  • Used to detect clicks inside/outside elements.
  • Example: parent.contains(child)
