Window Object

Key points

  • A window is a Object that is automatically created by the browser
  • It is a global Object and it is browser provided js Object
  • It is the Super Object for all other browser objects
  • It contains DOM , BOM , properties and methods etc
  • Also the alert, confirm, and prompt dialogs come under window object

Document Object Model(DOM)

Key points

  • All the content of the html file can be accessed in javascript.
  • as the total content of html is stored as an object named document
  • The document object is created by the browser when the HTML is loaded
  • so document is browser provided javascript object
  • And this Object is under the window Object
  • In simple words DOM is a representation of your HTML page as objects
  • console.log(document); gives you html and using dir gives js properties and all
  • document.body gives html as it is an Object (contains sub tags in it)
  • document.body can give null if script is written before the body
  • document.title gives string as it is not an Object or as it contains no tags in it, it is simple text.
  • we use DOM as it allows dynamic manipulation of the HTML content.

Browser Object Model(BOM)

  • BOM provides methods and properties to interact with the browser window.
  • BOM controls browser-related objects (not HTML).
  • Examples of BOM objects include location ,history,navigator,dialog methods-alert,confirm,prompt etc
  • other concepts discussed further.
