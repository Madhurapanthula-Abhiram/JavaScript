JavaScript Loops - Key Points

1. for Loop

  • Used when the number of iterations is known.
  • Structure: for (initialization; condition; increment)
  • Runs until the condition becomes false.
  • Best for counting loops.

2. while Loop

  • Used when the number of iterations is unknown.
  • Runs as long as the condition is true.
  • Condition is checked before each iteration.
  • Useful for user input or waiting until something happens.

3. do...while Loop

  • Runs the block at least once regardless of the condition.
  • Condition is checked after execution.
  • Useful when minimum one execution is required.

4. for...in Loop

  • Used to iterate over object properties.
  • Returns keys that are indices (property names).
  • best use of this loop is in Objects

5. for...of Loop

  • Used to iterate over iterables like arrays, strings, sets.
  • Returns values from the iterable.
  • Simpler and cleaner than a traditional loop for arrays.

6. forEach() Method

  • Array method that runs a function for each element.
  • Does not support break or continue.
  • Does not return a value (returns undefined).
  • Great for simple, clean array looping.

7. Loop Control Statements

  • break → Stops the loop immediately.
  • continue → Skips the current iteration.
  • Useful for filtering or early termination.
