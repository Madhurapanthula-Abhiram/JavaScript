Arrays in JavaScript

Arrays Key Points

  • Arrays are non primitive data types
  • Arrays are ordered collections of values.
  • That means they can store multiple values in a single variable of same data type or different data types but storing same data type is preferred for better performance and readability.
  • arrays are special type of Objects. with index as their keys.that is when you return the type of array it returns type as object data type
  • Arrays are mutable, meaning their elements can be changed after the array is created.
  • Array index starts from zero
