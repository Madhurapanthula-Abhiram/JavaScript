Adjacent HTML Insertion & Remove Methods

element.insertAdjacentHTML()

  • Used to insert HTML at specific positions
  • Does NOT replace existing content
  • Works with raw HTML string
  • Faster than innerHTML
  • No need to use createElement()
  • Example : box.insertAdjacentHTML("beforeend", "<p>Hello</p>");

beforebegin

  • Inserts HTML before the element
  • Placed outside the element (above)
  • Same position as before()
  • Example : box.insertAdjacentHTML("beforebegin", "<p>Before</p>");

afterbegin

  • Inserts HTML inside element at beginning
  • Placed as first child
  • Same position as prepend()
  • Example : box.insertAdjacentHTML("afterbegin", "<p>Start</p>");

beforeend

  • Inserts HTML inside element at end
  • Placed as last child
  • Same position as append()
  • Most commonly used position
  • Example : box.insertAdjacentHTML("beforeend", "<p>End</p>");

afterend

  • Inserts HTML after the element
  • Placed outside the element (below)
  • Same position as after()
  • Example : box.insertAdjacentHTML("afterend", "<p>After</p>");

element.remove()

  • Removes the element completely from DOM
  • Element is deleted, not just hidden
  • Simple and modern method
  • Example : element.remove();

insertAdjacentHTML vs append/prepend/before/after

  • In append/prepend/before/after we need to create element before insertion.
  • insertAdjacentHTML → works with HTML string so no need to create element direct one step.
  • And also using adjacent methods you can insert bulk content at once.
  • But in append..etc methods you should create ele then use loops and insert then.
  • Use append/before/after when:
    • You need JS control
    • You already have elements
    • You add event listeners and you need Security (user input)
  • Use insertAdjacentHTML when:
    • You have HTML string
    • You want fast insertion
    • You add bulk content

Key Position Mapping:

  • beforebegin → same as before()
  • afterbegin → same as prepend()
  • beforeend → same as append()
  • afterend → same as after()
