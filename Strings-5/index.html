Strings ,String Methods and Escape Characters

Strings basics

A string is a sequence of characters enclosed in:

  • "double quotes"
  • 'single quotes'
  • `template literals` (backticks)

String Characteristics

  • Strings are immutable
  • let s = "Hello"; s[0] = "Y"; // ❌ No effect s = "Yellow"; // ✔ Only reassigning works
