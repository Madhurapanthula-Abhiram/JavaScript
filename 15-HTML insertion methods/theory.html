HTML Insertion Methods in JavaScript

document.createElement()

  • Used to create a new HTML element
  • Element is created in memory (not visible initially)
  • Must be inserted into DOM using append/prepend/before methods etc
  • Very important for dynamic content creation
  • Example : let div = document.createElement("div");

element.className

  • Used to assign class to an element
  • Replaces existing class completely
  • That is if old class are there class="one two" and we set a class name to it as "three" the one and two are removed.
  • Accepts string of class names
  • Used for styling and DOM manipulation
  • Example : div.className = "box";

element.innerHTML

  • Used to insert HTML content inside element
  • Parses HTML tags
  • Replaces existing content
  • Can insert multiple elements at once
  • Example : div.innerHTML = "<h1>Hello</h1>";

element.innerText

  • Used to insert plain text and get the plaintext
  • Does not parse HTML tags
  • Displays exactly what is written
  • Safer than innerHTML and it does not display the hidden content
  • Example : div.innerText = "<h1>Hello</h1>";
  • it is shown as "<h1>Hello</h1>"; only as text

element.appendChild()

  • Used to add a node at the end of a parent element
  • Inserts element inside the parent (as last child)
  • Accepts only ONE node as argument
  • Does NOT accept text directly
  • Throws error if multiple arguments are given
  • Example : parent.appendChild(child);

element.append()

  • Adds element at the end of parent
  • Inserted inside the element
  • Can add multiple elements or text
  • Does not replace existing content
  • Example : parent.append(child);

element.prepend()

  • Adds element at the beginning of parent
  • Inserted inside the element
  • Opposite of append()
  • Does not remove existing content
  • Example : parent.prepend(child);

element.before()

  • Inserts element before the target element
  • Placed outside the element
  • Does not affect inner content
  • Useful for positioning elements
  • Example : element.before(newEl);

element.after()

  • Inserts element after the target element
  • Placed outside the element
  • Does not affect inner content
  • Commonly used for layout changes
  • Example : element.after(newEl);

element.replaceWith()

  • Replaces the element completely
  • Old element is removed from DOM
  • New element takes its place
  • Useful for dynamic updates
  • Example : element.replaceWith(newEl);

Key Differences

  • appendChild() → adds only one element
  • append() → adds at end inside element
  • prepend() → adds at beginning inside element
  • before() → adds before element (outside)
  • after() → adds after element (outside)
  • innerHTML → inserts HTML
  • innerText → inserts text
