JS DOM - className & classList Concepts

className

  • Used to set class names
  • Overwrites all existing classes
  • Example : t1.className = "grey align"
  • After change, old classes are removed

classList

  • Returns classes as DOMTokenList (array-like)
  • Used to manipulate classes individually
  • Example : console.log(t1.classList)

classList.add()

  • Adds one or more classes
  • Does not remove existing classes
  • Example : t1.classList.add("arran")
  • Multiple classes : add("arran","align","mod","red")
  • If multiple classes define same property → last CSS rule wins
  • JS order does NOT matter
  • CSS order decides final style
  • Example : "arran" overrides "red" if defined later

classList.remove()

  • Removes a specific class
  • Example : t3.classList.remove("grey")

classList.toggle()

  • Adds class if not present
  • Removes class if already present
  • Repeated toggling switches state
  • Example : t3.classList.toggle("arran")

classList.contains()

  • Checks if class exists
  • Returns true or false
  • Example : t3.classList.contains("red")

classList.replace()

  • Replaces one class with another
  • Example : t3.classList.replace("red","black")
  • Works only if old class exists
